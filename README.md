# Chess - Self Learning AI

This repository contains a chess engine and a self-learning AI with a pygame frontend (`ChessMain.py`).

Quick start (PowerShell on Windows):

```powershell
python -m pip install -r requirements.txt
python .\ChessMain.py
```

Notes:
- `ChessEngine.py` contains the game logic and `Move` class.
- `SelfLearningAI.py` contains the learning brain and move-finding logic.
- `ChessMain.py` is the pygame frontend.
- `ai_stats.json` records the AI's results so far.
